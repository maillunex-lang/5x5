# ETERNAL LEGENDS ONLINE v2.7: геройские способности и статусы

Добавлены индивидуальные автоматические эффекты: защитные щиты Айдара и Ардена, усиленный выстрел Айсылу, мощные удары Булата и Гаррока, прерывание Каэля, яд Морвены и Ноктиса, защитное благословение Ауриэль. Лечение Зарифы осталось в ранее реализованной системе поддержки.

Щит поглощает входящий урон; яд наносит периодический урон; оглушение временно блокирует атаки. Все статусы создаются заново при старте боя и не сохраняются между боями. Сохранения переведены на версию 10 без изменения путей сохранения.

Проверки: 118 Python статических тестов успешно; тесты не подтверждают GDScript runtime или Android APK. Для настоящей беты необходимы Godot 4, Android SDK и испытание на устройстве.

Никакие рабочие серверы, GitHub или другие игры не изменялись.
