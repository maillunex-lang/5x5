# ETERNAL LEGENDS ONLINE

Легенды Южного Урала: автономная 5×5 RPG на Godot 4 для Android.

## Статус

Репозиторий инициализирован. Полные исходники v7.1 пока находятся в отдельном проверенном ZIP-архиве и **ещё не опубликованы в этом репозитории**. Нельзя считать этот `main` готовым к сборке APK.

В локальном исходном проекте прошли 228 статических тестов. Запуск Godot и Android APK ещё не проверены.

## Безопасность

Не использовать рабочие серверы или исходники других игр для сборки. Публиковать игру целиком только после переноса и проверки всех файлов Godot.
