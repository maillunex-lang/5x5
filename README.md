# ETERNAL LEGENDS ONLINE · Легенды Южного Урала

Исходный проект **v7.1**: вертикальная Android RPG на Godot 4, автоматические бои 5×5, развитие персонажей и локальное сохранение.

**Статус:** игровой прототип. Это ещё не работающая MMO: серверы игры, аккаунты и мультиплеер отсутствуют.

## Возможности
- 10 героев, команда из 5 персонажей, передняя и задняя линии
- Автобои, классовые способности, противники, боссы и журнал боя
- 12 регионов Башкортостана, по 20 этапов
- AFK-награды, задания, экспедиции, экипировка, кузница и мастерство
- Локальные сохранения с резервной копией

## Запуск и проверки
Откройте `project.godot` в Godot 4 (проверено на 4.8.beta3).

```bash
python3 -m unittest discover -s tests -q
godot --headless --path . --editor --quit
godot --headless --path . --script res://tools/godot_smoke.gd
```

В версии v7.1 на Lunex: **228 Python-тестов OK**, Godot import OK, runtime smoke PASS (сцена, 5×5, бой, журнал, сохранение).

## Android APK
Debug APK можно собрать командой `bash tools/build_android.sh` при наличии Godot, Android SDK и экспортных шаблонов. Это сборка для тестирования, не релиз Google Play.
